# Gerenciador de Tarefas — Estudos

Sistema de gerenciamento de tarefas desenvolvido para estudos e prática de desenvolvimento Web.

O projeto contém o sistema completo da aplicação, incluindo interface, gerenciamento de dados, API, armazenamento local com LocalStorage e demais recursos necessários para seu funcionamento.

## Requisitos

Antes de executar o projeto, tenha instalado:

- **Node.js:** 22.13.x ou superior
- **Git**
- **VS Code** ou outro IDE/editor de código

## Instalação

Clone o repositório:

```bash
git clone https://github.com/0xKxbyte/Gerenciador-de-Tarefas_Estudos.git
```

Entre na pasta:

```bash
cd Gerenciador-de-Tarefas_Estudos
```

Instale as dependências:

```bash
npm install
```

Para Rodar:

```bash
npm run dev
```

Tailwind CSS:
Este projeto utiliza **Tailwind CSS v4**.
A instalação é feita através do `package.json`. Após clonar o projeto, execute:

```bash
npm install
```

Todas as bibliotecas e dependências utilizadas pelo projeto estão definidas no `package.json`. Caso seja necessário instalar ou atualizar alguma dependência, consulte esse arquivo.

## Estrutura

O projeto contém:

- Sistema principal da aplicação
- Sistema de API
- Sistema de armazenamento com LocalStorage
- Interface desenvolvida com React
- Estilização com Tailwind CSS
